# 身份证处理工具

一个纯浏览器本地运行的身份证处理工具。图片不上传服务器，所有处理都在访问者自己的电脑里完成。

## 功能

- 身份证抠图拼接：上传正反面照片，自动识别身份证边框，抠出四个角完整露出的证件图，上下拼接成一张图，导出 JPG
- 格式转换：PDF 转图片、图片转 PDF、图片格式互转（JPG / PNG）

Word、Excel、PPT 转图片在浏览器里做不到，这个功能请继续用桌面版工具。

## 在线使用

打开网址即可使用，不需要安装任何东西。手机和电脑都能开。

## 部署到 GitHub Pages

详细步骤见同目录的 部署步骤.md。

## 技术说明

- 边框识别：Canny 边缘、背景亮度差、自适应阈值三路候选，各自再做碎块合并，打分选最优，找不到就回退整幅图，永不失败
- 透视校正：向外扩张边缘后做反向映射加双线性插值采样，超出原图部分填白，因此四个角一定完整可见
- 零构建、零后端：只有 pdfjs-dist 一个外部库用于解析 PDF，其余全部手写
